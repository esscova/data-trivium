## Sobre

Este material reúne a base teórica do modelo relacional de bancos de dados, desde os conceitos de entidade, atributo e relacionamento até a normalização e a álgebra relacional, além de servir como referência de consulta rápida para a sintaxe SQL no PostgreSQL. Construo este guia durante a revisão do curso de Banco de Dados e Linguagem SQL com PostgreSQL, com o objetivo de consolidar em um documento único o que costuma ficar disperso entre anotações de aula e exercícios isolados.

A escolha do formato markdown, reflete a natureza do conteúdo, já que grande parte dele é conceitual e não depende de execução de código para ser compreendida. 

Os exemplos práticos de SQL presentes na seção de referência de sintaxe utilizam o [Ambiente PostgreSQL](https://github.com/esscova/data-trivium/tree/main/Banco%20de%20Dados/ambientes/postgres) via Docker já configurado no repositório, mantendo consistência com o restante do trabalho de banco de dados.

As seções deste guia estão organizadas na seguinte ordem:

1. Fundamentos do Modelo Relacional
2. Chaves e Integridade
3. Do Modelo Conceitual ao Lógico
4. Normalização
5. Álgebra Relacional
6. Referência de Sintaxe SQL (PostgreSQL)
7. Referências
